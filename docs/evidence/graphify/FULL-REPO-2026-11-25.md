## Checks

1. Symbols whose only non-test occurrence is their definition (repo-wide, and per Go package for
   unexported names). Interface methods (`MarshalJSON`, `Unwrap`), Rust `#[test]` functions, config
   keys and the HCIS reference `.d.ts` were excluded after checking them.
2. Cross-layer contracts: every frontend `/api/v1` URL matches a `Server.handle` route; every broker
   op the API calls is registered; every client deadline key is a registered op; every scope string
   used in the frontend, broker ops and module registry is in `auth.KnownScopes`.
3. Report sections: surprising connections (all real imports or INFERRED Rust intra-crate calls; one
   INFERRED `compact_data` → CI job `check` link is a false positive) and isolated nodes (types used only
   inside function bodies, which the extractor does not link).

1. **Ports page fix was never merged.** `edad4f2d` ("describe port bind scope, not reachability") was
   committed only locally and missed #163, so `main` still said "reachable beyond this host". It is
   re-applied here (`9aba4a7d`).
2. **Dead API client functions (`c83b15c4`).** `getLegacy` (plus its now-orphaned `Legacy` and
   `WebminCheck` types) and `previewTraefikLabels` had no caller. The UI reads Webmin state from the
   overview and previews Traefik labels through the platform preview. The backend routes stay documented API.
3. **Dead plugin helpers (`c83b15c4`).** `loadPlugin`/`unloadPlugin` were used only by a test. The
   Appearance menu toggles contributions with `setContributionEnabled`; the test now uses that path.

No change needed: the Ports page does not show `PortMap.notes`, but it already shows an equivalent
banner from `processesHidden`. Hardware section notes are shown under "Where this data comes from".
