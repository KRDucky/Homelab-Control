# ResourceTree

A keyboard-navigable tree of resources (WAI-ARIA tree).

**Status: Proposed (HCIS).** New in the HCIS specification; a reference design, not in the app.

Source: none in the repository.

## When to use

Use for datasets, folders, enclosures and the Resource Explorer. Nodes take `icon`, `status`, `meta`, `children`.

## Rules

- Arrow keys move and expand, Home/End jump, Enter selects.

Props: `ResourceTreeProps` in `reference/index.d.ts`. Preview data is fictional and labelled “Example data”.
