# ProgressBar

A thin determinate or indeterminate progress bar.

**Status: Planned.** Listed in the repository's planning docs but not implemented in the app yet.

Source: `docs/ui/01-DESIGN-SYSTEM.md §1.3 (ProgressBar)`

## When to use

Use inside JobProgress and long reads. Always give a `label`.

## Rules

- Indeterminate animation becomes a static bar under reduced motion.

Props: `ProgressBarProps` in `reference/index.d.ts`. Preview data is labelled “Example data”.
