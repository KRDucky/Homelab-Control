# NumericInput

A number field with stepper buttons, bounds and unit.

**Status: Proposed (HCIS).** New in the HCIS specification; a reference design, not in the app.

Source: none in the repository.

## Rules

- Arrow keys step; out-of-range input is clamped.

Props: `NumericInputProps` in `reference/index.d.ts`. Preview data is fictional and labelled “Example data”.
