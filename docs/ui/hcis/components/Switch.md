# Switch

An on/off setting that takes effect as part of a form or preview.

**Status: Planned.** Listed in the repository's planning docs but not implemented in the app yet.

Source: `docs/ui/01-DESIGN-SYSTEM.md §1.3 (Switch)`

## When to use

Use for settings, not for actions that change a host immediately; those still go through a preview.

## Rules

- role="switch" with a visible On/Off word.

Props: `SwitchProps` in `reference/index.d.ts`. Preview data is labelled “Example data”.
