# WorkspaceSwitcher

Switch between saved workspaces (layouts, columns, landing page).

**Status: Proposed (HCIS).** New in the HCIS specification; a reference design, not in the app.

Source: none in the repository.

## When to use

Suggested workspaces: System Monitoring, Storage Administration, Docker Management, Virtualization, Networking, Diagnostics. Workspaces never carry colours; basic navigation never depends on them.

Props: `WorkspaceSwitcherProps` in `reference/index.d.ts`. Preview data is fictional and labelled “Example data”.
