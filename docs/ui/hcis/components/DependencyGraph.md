# DependencyGraph

Columns of related resources with drawn links (host → drive → pool → dataset → mount → container).

**Status: Proposed (HCIS).** New in the HCIS specification; a reference design, not in the app.

Source: none in the repository.

## When to use

Use in Storage and the Resource Explorer. Selecting a node highlights its links.

## Rules

- Links are also listed as text for screen readers.

Props: `DependencyGraphProps` in `reference/index.d.ts`. Preview data is fictional and labelled “Example data”.
