# RiskBadge

The four HCIS risk classes as a word + icon: Read-only, Reversible, Disruptive, Destructive.

**Status: Proposed (HCIS).** New in the HCIS specification; a reference design, not in the app.

Source: none in the repository.

## Rules

- Never colour alone; Destructive also has a heavier border.
