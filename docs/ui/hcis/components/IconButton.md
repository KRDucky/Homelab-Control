# IconButton

A square button showing only an icon, with a required accessible label.

**Status: Planned.** Listed in the repository's planning docs but not implemented in the app yet.

Source: `docs/ui/01-DESIGN-SYSTEM.md §1.3 (IconButton)`

## When to use

Use in dense rows and headers where the icon is unambiguous. `label` is required and also becomes the tooltip.

## Rules

- Meets the 24px target minimum at every density.

Props: `IconButtonProps` in `reference/index.d.ts`. Preview data is labelled “Example data”.
