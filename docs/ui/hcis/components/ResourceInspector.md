# ResourceInspector

A side panel with a resource’s fields and its raw JSON.

**Status: Proposed (HCIS).** Not in the app or the planning docs yet; a reference design for future work.

Source: none in the repository.

## When to use

Use beside tables and grids to inspect a selection without leaving the page.

Props: `ResourceInspectorProps` in `reference/index.d.ts`. Preview data is labelled “Example data”.
