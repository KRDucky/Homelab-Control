# DetailPanel

A side panel for the selected resource. `floating` makes it a glass inspector.

**Status: Proposed (HCIS).** New in the HCIS specification; a reference design, not in the app.

Source: none in the repository.

## Rules

- Long troubleshooting text and forms go in opaque panels, not floating glass.

Props: `DetailPanelProps` in `reference/index.d.ts`. Preview data is fictional and labelled “Example data”.
