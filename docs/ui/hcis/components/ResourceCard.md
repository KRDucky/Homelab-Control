# ResourceCard

A card summarising one resource with a status, a headline metric and optional content.

**Status: Proposed (HCIS).** Not in the app or the planning docs yet; a reference design for future work.

Source: none in the repository.

## When to use

Use on overview and dashboard grids. Give `href` or `onClick` to make the whole card a link or button.

Props: `ResourceCardProps` in `reference/index.d.ts`. Preview data is labelled “Example data”.
